# 课程与选题要求

本文档整理自课程说明、课程设计要求和项目 A 选题说明。若 Canvas 后续通知发生变化，以课程平台通知为准。

## 课程目标

构建一个操作系统雏形，覆盖以下主线：

1. 工作环境搭建。
2. Boot Sector 制作。
3. 保护模式建立。
4. Loader 制作。
5. 内核雏形形成。
6. 加入中断处理。
7. 加入单进程支持。
8. 加入多进程支持。
9. 加入输入输出系统。

## 项目 A 范围

项目参考 OrangeS 的 x86 实现路线，但不能只运行或提交随书源码。小组需要理解并实现启动、内核、中断、进程、TTY、文件系统和系统调用等关键模块，再完成自定义扩展。

计划扩展包括：

- Shell 内置命令 `help`、`clear` 和未知命令提示。
- 用户态命令 `cat`、`stat`、`rm`。
- 命令构建、打包和安装流程。
- 可选的只读进程信息接口及 `ps` 命令。

## 评分信息

| 项目 | 占比 |
| --- | ---: |
| 文档及源码 | 30% |
| 项目难度 | 30% |
| 个人工作量 | 30% |
| 答辩 | 10% |

选题说明将项目定位为达到 B 级方向并向 A 级靠拢。B 级要求修改或重新实现参考源码的一个或多个模块，新增代码量至少达到相关模块代码量的一半；只有用户级或系统级应用扩展可能无法单独满足该目标，因此必须保留核心模块实现和修改的证据。

## 交付物

- 带阅读导航的 Word 或 PDF 项目文档。
- 源码托管链接，不提交单独源码压缩包代替链接。
- 可运行项目演示和关键运行截图。
- 答辩汇报；PPT 可选但建议准备。
- 环境、实现过程、问题与解决方法、验证结果和小组分工记录。

课程说明中给出的答辩截止时间为 **2026 年 9 月 13 日**，具体答辩安排以 Canvas 通知为准。

## 完成标准

- 仓库可以从文档描述的环境中完成构建，不依赖未记录的手工步骤。
- 系统可以正常启动并进入 Shell。
- 原有和新增命令可以通过可重复的测试场景演示。
- 每项核心实现和扩展都能对应到提交、作者、验证输出或截图。
- 项目文档能够解释代码结构、关键机制、自定义改动和问题处理过程。
