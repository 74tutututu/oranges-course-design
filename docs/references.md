# 参考资料与引用规则

## 主要参考资料

- 《Orange'S：一个操作系统的实现》及随书光盘源码。
- 随书源码第 11 章 `chapter11/c` 阶段版本，作为完整系统结构的主要阅读和对照对象。
- 课程提供的《2026 操作系统课程设计课程说明》和《操作系统课程设计要求》。
- 项目 A OrangeS 选题说明。

M2 阅读了随书源码 `chapter4/c` 的 FAT12 Loader 装载流程和 `chapter5/f` 的 GDT、A20、保护模式及 Kernel 交接思路。仓库中的 M2 代码按本项目的内存布局、错误处理和自动测试要求独立编写，没有复制参考源文件。

M3 阅读了随书源码 `chapter8/_base_` 的 IDT、8259A、PIT 和键盘 IRQ 组织方式。仓库中的 M3 代码使用独立的 C/汇编接口、链接脚本和 QEMU debug-exit 测试，不复制参考源文件。

参考资料保留在课程资料目录中，不复制到本仓库。当前仓库不包含随书源码或预生成磁盘镜像。

## 引用规则

- 阅读参考代码后自行实现时，在提交说明中写明参考模块和核心差异。
- 直接使用或改写代码时，在文件头或相邻注释中标明原作者、来源章节和修改人。
- 不删除参考代码中已有的作者或版权信息。
- 无法确认授权范围的内容不公开分发；提交远端前再次核对来源和课程要求。
- 项目报告区分“参考系统原有能力”“小组复现内容”和“小组新增功能”。
- 每个自定义功能记录设计、代码提交、测试证据和负责人。
