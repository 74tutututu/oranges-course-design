# 项目报告提纲

本提纲已落实为 `docs/report.md`，并可通过 `make report` 生成带目录的 `docs/OrangeS-course-design-report.docx`。以下结构保留用于核对报告覆盖范围。

## 1. 项目概述

- 选题背景与目标
- 小组成员和工作分工
- 自主实现范围与参考实现边界
- 最终功能和难度定位

## 2. 开发环境

- 宿主系统、容器、编译器、汇编器和模拟器版本
- 环境搭建步骤
- 32 位工具链兼容问题及解决方法

## 3. 系统总体设计

- 启动链路
- 内核模块关系
- 进程、文件系统、TTY 和系统调用设计
- 磁盘镜像及内存布局

## 4. 分阶段实现

每个阶段统一记录：实验目的或要求、实现步骤、关键代码、遇到的问题与解决方法、验证结果和阶段心得。

- Boot Sector
- 保护模式与 Loader
- 内核与中断
- 单进程与多进程
- 输入输出系统
- 文件系统与系统调用
- Shell 和命令扩展

## 5. 自定义扩展

- 功能需求和设计选择
- 与内核或系统调用的交互
- 相对参考系统的改动
- 正常与异常场景测试

## 6. 测试与演示

- 可重复的构建和启动步骤
- 启动、Shell 和命令截图
- 回归测试结果
- 已知限制

## 7. 项目管理

- 里程碑和提交历史
- 双人工作量说明
- 重要问题与决策记录

## 8. 总结

- 对操作系统机制的理解
- 项目不足
- 可继续改进的方向

## 参考资料

列出书籍、课程资料、源码和外部文档。引用或改写的代码必须能够追溯到具体来源。
